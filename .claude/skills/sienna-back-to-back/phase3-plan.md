# SIENNA back-to-back — Phase 3: overlap the pipeline stages

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> or superpowers:executing-plans to implement task-by-task. Steps use `- [ ]` syntax.

**Goal:** `sienna_top` runs up to three sets at once — one in the mesh, one in the
activation lanes, one in pooling — behind a credit interface, with results in issue order.

**Architecture:** The single outer FSM is replaced by two stage controllers, `G`
(activation: read a mesh result into FIFO1, fill the lanes, write `gpnae_out_mem`) and `P`
(pooling: dispatch windows, maxpool, dropout). The mesh is its own controller since phase 2.
`gpnae_out_mem` gets two banks: `G` writes one while `P` dispatches from the other. A
credit counter, initialised to `MAX_SETS_IN_FLIGHT` = 3, is decremented when the host's
start is accepted and incremented when `P` finishes a set. Every clear that used to be
keyed on the global `IDLE` is keyed on its own stage's idle state.

**Tech stack:** SystemVerilog, Verilator 5.035, Python 3 stimulus, farm runs via `blaunch`.

**Spec:** `SKILL.md` in this directory (Architecture; the six `IDLE` clear points; Testing).
Phase 2 plan: `phase2-plan.md`.

- No sticky completion flags. `pipeline_complete_o` becomes a one-cycle pulse.
- Per-set data must be random and distinct; set 0 keeps each test's named pattern.
- One-line comments, no attribution lines, one change per commit, push when done.

## Interface contract (top level, new)

| Port | Dir | Meaning |
|---|---|---|
| `pipeline_ready_o` | out | a credit and a mesh staging bank are free: host may load a set and pulse start |
| `start_pipeline_i` | in | one-cycle pulse after loading; ignored while `pipeline_ready_o` is low |
| `pipeline_complete_o` | out | one-cycle pulse: the last output of a set has left dropout |
| `done_set_id_o` | out | 2-bit id of that set, counting accepted starts mod 4 |

## Review focus

- A set's outputs attributed to the wrong set: the TB slices the output stream at each complete pulse and checks the count and the set id. (Task 1)
- A stage finishing without real work (the stale-flag class): every set's slice is compared with its own distinct golden output. (Task 1)
- More than three sets in flight: the TB tracks started minus completed. (Task 1)
- The old single-set and `BACK_TO_BACK` flows must keep passing with a pulsed `pipeline_complete_o`. (Task 2 run)
- A timeout must fail `make regression`, not exit 0. (Task 1, `regression.py`)

### Task 2: Stage controllers, activation banks and credits

**Files:** `src/sienna_top.sv`, `testbenches/TB_sienna_top.sv` (diagnostics that named `current_state`)

- [ ] **Step 1:** Replace `pipeline_state_t`/`current_state` with `g_state_t {G_IDLE, G_FEED, G_LATCH, G_ROUND}`
and `p_state_t {P_IDLE, P_DISPATCH, P_WAIT}`. At the old outer-FSM site:

```systemverilog
  assign pipeline_ready_o = (credits != 0) && mesh_input_ready;
  assign host_accept = start_pipeline_i && pipeline_ready_o && !north_queue_empty && !west_queue_empty;
  assign g_accept  = (g_state == G_IDLE) && systolic_collection_complete && !act_full[act_wr];
  assign g_done    = (g_state == G_ROUND) && all_collected;
  assign p_accept  = (p_state == P_IDLE) && act_full[act_rd];
  assign p_release = (p_state == P_DISPATCH) && disp_done;  // the bank is copied into FIFO2
  assign pool_done = (p_state == P_WAIT) && streaming_complete;
```

One `always_ff` steps both FSMs, sets `act_full[act_wr]` on `g_done` and clears
`act_full[act_rd]` on `p_release` (flipping the pointers), updates
`credits <= credits - host_accept + pool_done`, the mesh set count, and the three set-id
counters. `systolic_start` becomes `assign systolic_start = host_accept;` (the mesh queues
it). `pipeline_complete_o = pool_done`, `done_set_id_o = p_set_id`.

- [ ] **Step 2:** Rekey every clear. `IDLE` clears become `g_state == G_IDLE` (total_elements,
fill FSM, systolic read) or `p_state == P_IDLE` (dispatcher, mp FSM, dropout count).
`FEED_GPNAE_FIFO` -> `G_FEED`, `LATCH_GPNAE_COUNT` -> `G_LATCH`, `GPNAE_ROUND` -> `G_ROUND`
(fill FSM, `fifo1_rd_ready`, `gpnae_out_mem` write), `DISPATCH_WINDOWS` -> `P_DISPATCH`,
`WAIT_DOWNSTREAM || PIPELINE_COMPLETE` -> `P_WAIT`.

- [ ] **Step 3:** `gpnae_out_mem[0:2*SRAM_DEPTH-1]`; writes add `act_wr ? SRAM_DEPTH : 0`, the
dispatcher's reads add `act_rd ? SRAM_DEPTH : 0`.

- [ ] **Step 4:** Busy outputs: `systolic_busy_o = mesh_sets != 0`, `gpnae_busy_o = g_state != G_IDLE`,
`maxpool_busy_o = (p_state != P_IDLE) && any_mp_active`.

- [ ] **Step 5:** TB diagnostics: replace `dut.current_state` with a TB wire
`{dut.g_state, dut.p_state}`.
