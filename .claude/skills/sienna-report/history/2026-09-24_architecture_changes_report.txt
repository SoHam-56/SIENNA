5. WHAT LIMITS IT NOW
----------------------------------------------------------------------------------------------------
   Activation, and in it the serial tail path (~270 cycles per out-of-range input, one at a time
   per lane). It matters more as N grows, because each output sums more products. Next fix:
   interleave several tail elements through gpnae_tail's units, as barrel_mac does for the
   polynomial. Also missing for real layers deeper than N: an accumulate-without-activation pass.
