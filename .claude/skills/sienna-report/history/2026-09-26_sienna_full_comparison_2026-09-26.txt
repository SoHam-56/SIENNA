SIENNA: EVERY CONFIGURATION MEASURED, AGAINST REFERENCE EDGE DEVICES (2026-09-26)
======================================================================================================================
All SIENNA numbers are Verilator RTL simulation on the farm, fp32. Time assumes a 950 MHz clock: NO timing run exists.
GFLOPS count 2 per multiply-accumulate of the workload. TOPS = GFLOPS / 1000. Latency = one set (or one inference) through
an empty pipeline. Throughput = steady state with sets streamed back to back. No power or area figures exist yet.
