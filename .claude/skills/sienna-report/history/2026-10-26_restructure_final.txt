Batch A (format package and one top)
  - ArithmeticLibrary: sienna_fmt_pkg with a define map (+define+FMT_FP32/BF16/INT8; no define builds fp32), one math module per
    function and width (bf16Multiplier, bf16Adder, bf16WideMultiplier, fp32ToBf16, int8/16/24 multipliers, int32Adder), the
    fmt_mul/fmt_add wrappers, the generic int8Requantizer and int8QuantizedAdder (no TFLite-named units), reference benches on
    SoftFloat DPI and a C integer reference, truefn.py, check_fmt, equivalence and exhaustive harnesses.
  - SIENNA, GPNAE, SystolicMesh: one top module per repo with a DATA_WIDTH datapath; the define picks the math; no per-format copies.
    sienna_top is SIENNA's only top (SET_PORT 0 layer contract, 1 set contract; COPIES).
  - Equivalence: the Batch A heads equal B in every output word (71.2 M), cycle (429 592), simulation time and true-function
    verdict over 11 515 files (restructure_batchA_comparison.log).
Batch B (GPNAE's activation lane, design D)
  - Fitted polynomial pieces per function instead of the Taylor series of e^x; a constant past the point where the function is within
    tolerance of its limit; a barrel multiply-add unit that starts a step every cycle.
  - Programmable coefficient memory (128 words: coefficients, piece bounds, degrees), reset contents = the fitted sets, written by the
    host between layers; a write while any element is in flight is refused (interlock, coef_ready_o), checked by assertions and the
    fault points.
  - Three accuracy tiers per function, gated at their own tolerance: tier 0 1%, tier 1 5%, tier 2 10%; each layer picks its tier.
  - Every lane output gated against numpy float64 (the true function) at its tier's tolerance; the bit-exact model is a diagnostic.
  - Removed: the published Taylor lane (kept as tag gpnae_taylor_final), the old coefficient ROM, every Vivado file and target, dead
    benches and scripts (deletions authorized by Soham, 2026-10-24/25).
VCS and standalone machine
  - SIM=vcs in every repo (targets, X/Z detection, === / !== compares on DUT data), never run here (no license, by ruling).
  - requirements.txt, no /proj paths, models/ with the four MLPerf Tiny models (Apache 2.0, NOTICE), fetch scripts:
    models/fetch_cifar10.sh (CIFAR-10, md5-checked) and models/fetch_inputs.sh (the kws and ad01 inputs, sha256-checked).
Uniform layout (pure rearrangement)
  - Every repo: src/ by function, testbenches/top/ + testbenches/units/, scripts/, one Makefile. SIENNA's four top benches folded into
    TB_sienna with MODE (make TB_MODE=pipeline|layer|sets|copies); src/sienna_rtl.f is the synthesis file list.
Generic int8 path
  - The int8 pipeline is framework-neutral: int32 sums, the generic per-channel requantize (int8Requantizer), the int8 ADD
    (int8QuantizedAdder) and fixed-point GPNAE; TFLite is one front end in model_runner, not a name in the RTL.
